Banking System
A simple banking system implemented in Python using Pandas and NumPy.
Features
•	Account creation with initial balance
•	Deposit and withdrawal functionality
•	Transaction history management (current balance only)
Dependencies
•	Python 3.x
•	Pandas
•	NumPy
Installation
To use this project, simply clone the repository and install the dependencies using pip:
git clone https://github.com/<your-username>/Banking-System.git
cd Banking-System
pip install pandas NumPy
Usage
Creating an Account
Create a new account with an initial balance using the create account method:
from banking system import Banking System

bank = Banking System ()
bank. create _account (1234, 1000)
Depositing Funds
Deposit funds into an account using the deposit method:
bank. Deposit (1234, 500)
Withdrawing Funds
Withdraw funds from an account using the withdraw method:
bank. Withdraw (1234, 200)
Getting Account Balance
Get the current balance of an account using the get _balance method:
print (bank.get_balance (1234)) 
Getting Transaction History
Get the transaction history of an account (current balance only) using the get_transaction_history method:
Print (bank.get_transaction_history (1234))
